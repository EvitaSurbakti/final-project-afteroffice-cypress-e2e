cypress-final-afteroffice

Proyek otomasi pengujian end-to-end (E2E) berbasis Cypress untuk tiga alur situs publik: Agoda, Amazon, dan YouTube.

Ringkasan

ItemNilai
FrameworkCypress ^16.2.0
Reportercypress-mochawesome-reporter ^5.0.0 (laporan HTML)
Pola desainPage Object Model (POM)
Viewport default1920 × 1080
Rekaman videoAktif (video: true)
Timeout perintah10.000 ms
ModulCommonJS ("type": "commonjs")

Tiga skenario yang tersedia:

  • Task 1 – Agoda: memesan tiket pesawat Jakarta → Singapura paling awal untuk besok dengan Malaysia Airlines.
  • Task 2 – Amazon: mencari “chair”, mengurutkan dari harga tertinggi, lalu memvalidasi detail produk.
  • Task 3 – YouTube: membuka video trending ke-3 di kategori Game dan memvalidasi judul serta nama channel.

Instalasi & Menjalankan

Prasyarat

  • Node.js (versi yang didukung Cypress 16) dan npm
  • Koneksi internet (pengujian menyasar situs live)
  • Browser Chrome/Edge/Electron

Instalasi

npm install

Membuka Cypress (mode interaktif)

npx cypress open

Menjalankan headless

# semua spec
npx cypress run

# satu spec saja
npx cypress run --spec "cypress/e2e/tests/agoda.cy.js"
npx cypress run --spec "cypress/e2e/tests/amazon.cy.js"
npx cypress run --spec "cypress/e2e/tests/youtube.cy.js"

# memilih browser
npx cypress run --browser chrome
Catatan: script npm test di package.json masih placeholder (“no test specified”). Gunakan perintah npx cypress ... di atas.

Flag browser (before:browser:launch)

Ditambahkan untuk mencegah crash renderer/GPU di halaman video YouTube:

  • --autoplay-policy=user-gesture-required – video tidak autoplay
  • --mute-audio
  • --disable-gpu
  • --disable-accelerated-video-decode
  • --disable-dev-shm-usage

Arsitektur (Page Object Model)

Pemisahan tanggung jawab:

  • Page Object (cypress/e2e/pages/*.js) – kelas berisi selector dan aksi halaman; setiap file mengekspor satu instance (export default new XxxPage()).
  • Spec (cypress/e2e/tests/*.cy.js) – menyusun langkah skenario dan menulis assertion.
  • Alias – nilai yang dibaca di satu halaman (nama, harga, jam) disimpan dengan cy.wrap(...).as('nama') lalu dibandingkan di halaman berikutnya via cy.get('@nama').

Skenario Pengujian

Task 1 – Booking Flight Agoda agoda.cy.js

  1. Buka Agoda, pilih menu Flights.
  2. Isi rute Jakarta → Singapore.
  3. Pilih tanggal besok (dihitung dinamis, format YYYY-MM-DD), klik Search.
  4. Filter maskapai Malaysia Airlines (kode MH), urutkan berdasarkan waktu keberangkatan, simpan jam berangkat & tiba tiket pertama.
  5. Pilih tiket Malaysia Airlines, isi data penumpang dari fixture passenger, simpan total harga.
  6. Lanjut ke pembayaran.

Assertion di halaman pembayaran:

  • Total harga sama dengan di halaman data penumpang.
  • Nama penumpang = firstName + ' ' + lastName.
  • Detail penumpang memuat nomor paspor.
  • Jam keberangkatan dan kedatangan sama dengan yang dipilih.

Task 2 – Search Item Amazon amazon.cy.js

  1. Set viewport 1920×1080, buka Amazon.
  2. Cari “chair”, urutkan harga tertinggi (price-desc-rank), aktifkan filter Free Shipping.
  3. Pilih item non-iklan (tanpa label “Sponsored”) pada baris pertama, simpan nama & harga.

Assertion di halaman detail: #titleSection memuat nama yang disimpan, dan harga (#apex-pricetopay-accessibility-label) memuat harga yang disimpan.

Task 3 – YouTube Gaming youtube.cy.js

  1. Set viewport 1280×720, buka YouTube (bahasa Indonesia).
  2. Buka sidebar (tombol “Panduan”), klik “Tampilkan lebih banyak”.
  3. Pilih menu Game, klik “Lihat semua” pada section “Video trending”.
  4. Ambil video ke-3 (index 2), simpan judul & channel, lalu klik video.

Assertion di halaman video: judul (#title > h1 > yt-formatted-string) dan channel (#owner-name > a) sama dengan yang disimpan.

Perhatian: agoda.cy.js dan youtube.cy.js memakai it.only, sehingga hanya test itu yang dijalankan di spec masing-masing. Hapus .only bila ingin menjalankan semua test di file tersebut.
